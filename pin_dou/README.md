# 拼豆图纸生成器

本地打开一个零依赖网页工具，把普通图片转成拼豆图纸。

## 功能

- 上传图片并生成像素化拼豆图纸
- 内置 MARD 221 色卡，自动匹配最近色号
- 支持设置目标宽高、颜色数量、取景方式和简单预处理
- 输出带网格和色号的图纸
- 自动统计每种色号所需颗数
- 导出图纸 PNG、材料清单 CSV，或直接打印成 PDF

## 运行

直接打开 [index.html](/Users/caicai/Desktop/pindou/index.html) 也可以使用。

如果你想走本地服务：

```bash
cd /Users/caicai/Desktop/pindou
npm start
```

打开 `http://127.0.0.1:4173`

## 色卡来源

内置 `MARD 221` 色号表，数据依据拼豆工具站公开色卡页面整理。
